Rowser

A web browser written in Rust and GPUI — with an engine built entirely from scratch. What you are reading right now was tokenized, parsed, laid out, shaped, and rasterized by code that lives in this repository.

What works

  • Multi-process architecture — one renderer per tab
  • HTML parsing with implied end tags & entities
  • Block & inline layout with word wrapping
  • TrueType fonts: cmap, glyf outlines, kerning
  • Supersampled scanline rasterization

Font showcase

Bold text, italic text, bold italic, monospace code, small text, big text, H2O, x2, underlined, and struck through.

Typography test

Avenue — WAVE — ToVe — typeset with real kerning. The quick brown fox jumps over the lazy dog. 0123456789. Pack my box with five dozen liquor jugs! How vexingly quick daft zebras jump.
